# 代理者規程

## 第1条（目的）
本規程は、ソラハ電機株式会社（以下「会社」という。）において、役職者が不在のときに承認を代行する代理者を定めることにより、承認手続の停滞を防ぎ、業務を円滑に進めることを目的とする。

## 第2条（定義）
本規程において「不在」とは、出張、休暇、病気その他の事由により、役職者が承認を行うことができない状態をいう。

## 第3条（代理者の指定）
1. 役職者が不在のときに承認を代行する代理者を、次の一覧のとおり定める。
2. 代理者は役職で定めるものとし、該当する者の氏名は役職者一覧による。

| 不在となる役職者 | 代理者 |
|---|---|
| 営業部長 | 営業部副部長 |
| 製造部長 | 製造部課長 |
| 開発部長 | 開発部課長 |
| 経理部長 | 経理部課長 |
| 人事部長 | 人事部課長 |
| 情報システム部長 | 情報システム部課長 |
| 法務室長 | 管理本部長 |
| 事業本部長 | 管理本部長 |
| 管理本部長 | 事業本部長 |
| 代表取締役社長 | 管理本部長 |

## 第4条（代理者も不在の場合）
1. 代理者も不在の場合は、さらにその代理者の定めに従う。
2. 前項の例として、法務室長が不在で、その代理者である管理本部長も不在の場合は、前条の一覧における管理本部長の代理者である事業本部長が承認を代行する。

## 第5条（代理者の責務）
1. 代理者は、本来の役職者と同等の注意をもって承認を行わなければならない。
2. 代理者は、代行した承認の内容について、本来の役職者が不在でなくなった後、速やかにその役職者へ報告する。

## 第6条（氏名の取扱い）
本規程には個人の氏名を記載しない。代理者に該当する者の確認は、役職者一覧を参照して行う。

## 附則
本規程は、制定の日から施行する。
