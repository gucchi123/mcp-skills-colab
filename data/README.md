# MCP×Agent Skills 講座のデータ（すべて架空）

> **このフォルダに登場する会社・人物・製品・取引先・連絡先・数値・文書は、すべて講座用の架空のものです。実在の企業・団体・個人とは関係ありません。**
> 会社は GraphRAG・LangGraph 講座と同じ架空の「ソラハ電機株式会社」です。電話番号は 03-0000-xxxx（割り当てのない局番）、メールは予約済みの .example です。

## 作り方

```
python make_data.py     # 経費・問い合わせ・契約・在庫・月次 (LangGraph 講座と同じもの。SEED = 20261018)
python make_extra.py    # 顧客台帳・社員・顧客情報取扱規程・攻撃入りデータ・道具を選ばせる問い (SEED = 20261024)
python check_data.py    # 規程から書き直した規則で正解を照合
python check_extra.py   # 顧客情報の「見てよい項目」189 組と、道具の名前を照合
```

## 仕込んだ筋（講座で使う）

- 経費: 境界値（ちょうど 10,000 円・1 人 1,500 円・申請期限当日）、休日でも交通費と書籍費は確認不要、部長の申請は本部長が承認する、など。
- 問い合わせ: 安全に関わる不具合（発熱・煙・膨らみ）はすぐ人へ。返品は「30 日以内かつ未開封」だけ自動で答えられる。
- 契約: 当社の賠償に上限がない・自由に再委託できる・外国法、のどれかがあれば法務室へ。
- 発注: 発注点より上なら「不要」。主の発注先が取引停止なら代わりへ、代わりも無ければ人へ。承認を省く依頼でも省かない（O-08）。
- 月次: 8 月に通信ゲートウェイ GW-5 の不具合で問い合わせが増え、GW-5 の売上が落ちた（GraphRAG 講座の問い合わせログと同じ筋）。9 月に持ち直す。
