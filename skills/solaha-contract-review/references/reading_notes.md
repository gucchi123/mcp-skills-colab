# チェックリストの読み方 (ソラハ電機・架空)

当社 = ソラハ電機株式会社 (契約書の「甲」)。相手方 = 「乙」。

| 番号 | 当たるとき | 読み方の注意 |
|---|---|---|
| R1 | 自動更新があり、解約の予告期間が **90 日以上** | 89 日以下なら当たらない。「3 か月前」は 90 日以上として扱う。自動更新が無ければ予告期間が長くても当たらない |
| R2 | **当社の**賠償責任に上限がない | 「甲が乙に対して負う損害賠償」の条を見る。乙の上限ではない。上限の定めが書かれていなければ「上限がない」 |
| R3 | **相手方の**賠償上限が月額料金の 1 か月分以下、または上限の定めがない | 「乙が甲に対して負う」の条を見る。2 か月分・3 か月分なら当たらない |
| R4 | 再委託 | 「再委託してはならない」「事前の書面による承諾を得た場合に限り」→ 当たらない。「甲に通知することにより」→ 中。「その裁量により」「自由に」「承諾なく」→ 高 |
| R5 | 準拠法が日本法以外 | 日本法なら当たらない |
| R6 | 管轄が東京地方裁判所以外 | 東京地方裁判所の専属的合意管轄なら当たらない。大阪地方裁判所・海外の裁判所などは当たる |
| R7 | 秘密保持の条項がない | 条の見出しに「秘密保持」が無くても、秘密情報の扱いを定めた条があれば当たらない |
